Part A: Retention & Theoretical Rules

Diagnostic MCQs (4 Items)

Q1 ($\varepsilon$-Closure Invariant): In an NFA with $\varepsilon$-transitions, what is the exact condition under which the $\varepsilon$-closure of a state $q$ is strictly equal to the singleton set $\{q\}$ (i.e., $\text{E-set}(q) = \{q\}$)? *

Q2 (Accepting Criterion in Subset Construction): Let $M_{\text{DFA}}$ be an automaton constructed via Subset Construction. Under what formal condition is a compound state $S = \{q_1, q_2, \dots, q_k\}$ designated as an accepting state? *

Q3 (Theoretical Necessity of Trap State): What is the formal theoretical necessity of introducing a "Dead State" (Trap State) when transforming an arbitrary NFA into a DFA? *

Q4 (Equivalence Partitioning Invariant): In Moore's or Hopcroft's DFA minimization, what foundational principle justifies partitioning states initially into $P_0 = \{Q \setminus F, F\}$? *

Part B: Near-Transfer & Algorithmic Tracing

Algorithmic Context 1

Problem Specification 1:

Consider an NFA over alphabet $\Sigma = \{0, 1\}$ with states $Q = \{A, B, C\}$, start state $A$, and accept state $C$.

• State A: reads '0' $\to \{A\}$; reads '$\varepsilon$' $\to \{B\}$

• State B: reads '1' $\to \{C\}$; reads '0' $\to \emptyset$; reads '$\varepsilon$' $\to \emptyset$

• State C: reads '0' $\to \{C\}$; reads '1' $\to \emptyset$; reads '$\varepsilon$' $\to \emptyset$

Q5 (Start State Formation): Applying the formal subset construction algorithm to Context 1, what is the exact initial state $q_{0\_\text{DFA}}$ of the resulting DFA? *

Q6 (Step Computation on Symbol '0'): From the initial DFA state $\{A, B\}$, evaluate the exact target state upon reading input symbol '0': $\text{E-set}(\text{Move}(\{A, B\}, 0))$. *

Q7 (Step Computation on Symbol '1'): From the initial DFA state $\{A, B\}$, evaluate the exact target state upon reading input symbol '1': $\text{E-set}(\text{Move}(\{A, B\}, 1))$. *

Q8 (Complete State Count & Minimization): After constructing all reachable states and computing transitions, what is the exact number of states in the fully minimized equivalent DFA? *

Part C: Far-Transfer & System Generalization

System Optimization MCQs

Q9 (Equivalence Under Application Semantics): An embedded protocol parser has two distinct accept states: $S_{\text{HTTP\_OK}}$ (emits 200) and $S_{\text{WS\_OK}}$ (emits 101). Both states loop back to themselves on any character in $\Sigma$, and neither has transitions to other states. The downstream microservice treats both codes identically. Can these two states be merged during Moore state minimization? *

Q10 (Microcontroller Memory Optimization): An engineer implements a DFA parser on an 8-bit microcontroller using a flat transition matrix array $(\text{State} \times \text{Symbol})$. What is the exact memory footprint reduction when minimizing a DFA from 5 states to 3 states over an alphabet $|\Sigma| = 4$? *
